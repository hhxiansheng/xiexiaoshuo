网络小说 AI 写作台

基于完整的网文创作方法论，从需求确认 → 金手指设计 → 大纲生成 → 章节写作，全流程可视化。
所有内容以 Markdown 文件形式存到你的本地文件夹，可备份、可同步。

第一步：选择作品文件夹

授权一个本地文件夹，作为一本小说的根目录（建议新建空文件夹）。所有设定、大纲、章节都会写入这里。
请使用 Chrome 或 Edge 浏览器。

检测到上次的作品

上次访问过作品文件夹「」，浏览器需重新授权。

已有作品 / 开始新书

选择文件夹后，若该文件夹已有设定/大纲，会自动载入；否则进入新书向导。

使用流程
  1. 右上角「设置」填入 AI 的 API 地址、Key、模型名（任意 OpenAI 兼容服务）
  2. 选择作品文件夹（本地空文件夹）
  3. 新书向导：需求确认 → 金手指 → 大纲 → 写第一章
  4. 之后随时在「写作」页继续写、改、保存

⚙️ AI 设置

配置大模型 API。支持任意 OpenAI 兼容服务（DeepSeek / OpenAI / 通义千问等）。

DeepSeek: https://api.deepseek.com/v1 ｜ OpenAI: https://api.openai.com/v1
小说创作建议 0.8 - 1.0
